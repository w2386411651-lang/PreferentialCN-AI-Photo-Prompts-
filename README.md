# Preferential CN AI Photo Prompts

面向中国用户的 AI 照片提示词收藏。  
Chinese-focused AI photo prompt collection.

这个仓库的用法很简单：放一张示例照片，然后把对应提示词写在照片下面。

## 示例 001：标题写这里

把图片上传到 GitHub 后，在这里显示：

```markdown

```
